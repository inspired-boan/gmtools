# GM工具

一款为 TRPG 跑团设计的桌面端 GM（游戏主持人）工具：以「树形目录 + 笔记 + 表格 + 卡片」组织你的规则、模组与备团资料，并提供跑团时的数据中台——共享变量白板。

> 本项目由 AI（Claude）辅助设计与开发，详见下文「关于」。

## 功能总览

### 核心组织（v1）

- **树形目录**：任意嵌套，规则 / 模组 / 备团 / 跑团自由组织；复制、拖拽排序、删除进回收站
- **笔记节点**：所见即所得 Markdown 编辑，支持本地图片（自动收纳到数据目录），自动保存
- **表格节点**：增删行列、文本 / Markdown 两种单元格、列宽拖拽、卡片视图（按模板把每行渲染成卡）
- **全局搜索**：全文检索（支持中文子串），命中笔记与表格单元格，点击跳转定位
- **数据安全**：整库导出 / 导入（zip 备份）；节点级 JSON 导出（含图片内嵌），方便分享模组；回收站可恢复

### 卡片与模板系统（v2）

- **模板编辑器**：7 种输入组件（文本 / Markdown / 数字 / 下拉 / 图片 / 分组 / 风格区块），12 列栅格拖放布局，5 套预设主题，3 种卡片尺寸，组件样式可覆盖
- **卡片节点**：选模板 → 左填写右实时预览；单卡导出自动内嵌模板，导入即完整可渲染
- **表格卡片视图**：表格列映射到模板组件，每行渲染成一张卡片

### 模板库 / 卡片库 / 跑团面板（v3）

- **模板库 / 卡片库**：挂载在规则下的收藏夹；收藏 = 深拷贝快照（可随时「同步自来源」）；库内完整卡面预览；创建卡片时可直接选用库中模板
- **跑团面板**：白板式界面，把树里的卡片（PC 卡、据点卡……）拖上画布自由摆位，画布平移缩放、视口记忆
- **共享变量中台**：面板级变量表；卡片字段可绑定变量（一处修改，全面板实时联动）；数字字段悬停 ±1（右键 ±5），跑团时顺手改数值
- **面板导出 = 完整存档**：摆位 + 变量 + 引用的全部卡片（含模板）打包，导入自动重建

## 技术栈

| 层 | 技术 |
|---|---|
| 应用框架 | Tauri 2（Rust） |
| 前端 | React 18 + TypeScript + Vite |
| 样式 | Tailwind CSS（自定义设计 token，奶油底 + 珊瑚色 + 衬线标题） |
| 状态 | zustand |
| 富文本 | TipTap |
| 数据 | SQLite（rusqlite）+ FTS5 全文索引 |

## 开发与构建

```bash
# 安装依赖（需要 Node.js 18+ 与 Rust 工具链）
npm install

# 开发模式（热更新）
npm run tauri dev

# 打包 Windows 安装包（NSIS）与绿色版 exe
npm run tauri build
```

数据默认存储于系统用户数据目录（Windows 为 `%APPDATA%\com.gmtools.app\`），可在应用设置中更改位置并一键打开，方便备份。
